# 🎓 Udemy Homepage Clone

A responsive, pixel-perfect front-end clone of the **Udemy** homepage built using semantic **HTML5**, **CSS3 (Flexbox)**, and **Google Fonts**. 

This project demonstrates core front-end web development concepts, including flexbox layout techniques, responsive design without external frameworks, UI component architecture, and clean styling practices.

## ✨ Features & Sections

- **Header / Navbar:** Includes the Udemy logo, category dropdown, search bar, cart with item counter, wishlist, login/signup buttons, and language selector.
- **Category Menu Bar:** Horizontal navigation showcasing course categories like *Development*, *Business*, *Design*, *IT & Software*, and more.
- **Hero Section:** Banner highlighting top promotional offers and learning pathways.
- **Recommended Courses:** Grid layout displaying course cards with images, instructor details, star ratings, price tags, and bestseller badges.
- **Recommended Topics:** Interactive topic pill tags and an input form for users to suggest new topics.
- **Popular Courses:** Featured section sorted by top ratings and learner reviews.
- **Footer:** Complete footer layout with quick navigation links, language picker, and copyright notice.
- **Responsive Layout:** Adaptive styling using CSS Flexbox for seamless browsing across various desktop screen sizes.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure for accessibility and clean SEO practices.
- **CSS3:** Flexbox layout system, CSS custom variables, and modern styling rules (no Bootstrap or CSS frameworks used).
- **Google Fonts:** Custom typography powered by Google Fonts (`Poppins` & `Inter`).
- **FontAwesome / Material Icons:** Vector icons for search, shopping cart, stars, and navigation buttons.
